# VPN на AmneziaWG (ООО «Тридит»)

Конфигурация VPN-сервера `pm-vpn.3dit.ru` (UDP 51820) и 150 клиентских подключений. Клиенты направляют
через VPN **только** подсети из `allowed-ips.txt` (заблокированные сервисы), остальной трафик идёт напрямую.
Каждому сотруднику выдаётся личный QR-код: он открывает личную страницу со скачиванием конфига и инструкцией.

## Что где лежит

| Файл | Назначение |
|---|---|
| `allowed-ips.txt` | Подсети, которые уходят через VPN (попадают в `AllowedIPs` клиентов) |
| `scripts/generate.py` | Ключи, серверный `awg0.conf`, клиентские `.conf` |
| `scripts/build_site.py` | Личные страницы, токены ссылок и QR-коды |
| `scripts/install-server.sh` | Установка AmneziaWG на Ubuntu и запуск `awg0` |
| `scripts/setup-web.sh` | nginx + сертификат Let's Encrypt + публикация личных страниц |
| `scripts/fetch-apps.sh` | Загрузка официальных релизов Amnezia для раздачи с сервера (`/apps/`) |
| `deploy/nginx-*.conf` | Шаблоны конфигурации nginx |
| `clients.csv` | Список клиентов: имя, IP в туннеле, публичный ключ (секретов нет) |
| `secrets.tar.age` | **Зашифрованные** ключи, токены ссылок и параметры обфускации |

Репозиторий публичный, поэтому приватные ключи и токены хранятся только в `secrets.tar.age`
(шифрование [age](https://github.com/FiloSottile/age)). Ключ расшифровки `age-key.txt`
в git не попадает: храните его в менеджере паролей. Без него подключения не восстановить.

## Восстановление из репозитория

```bash
git clone https://github.com/3dit-lab/vpn && cd vpn
age -d -i /путь/к/age-key.txt secrets.tar.age | tar xz      # создаст secrets/state.json
pip install cryptography "qrcode[pil]"
python3 scripts/generate.py   --endpoint pm-vpn.3dit.ru --port 51820 --clients 150
python3 scripts/build_site.py --domain pm-vpn.3dit.ru
# результат в out/: server/awg0.conf, clients/*.conf, site/c/<токен>/, qr/*.png, qr-links.csv
```

Ключи, токены и параметры обфускации берутся из `secrets/state.json` и не меняются, поэтому клиентские
конфиги, ссылки и уже напечатанные QR остаются прежними.

## Развёртывание на сервере (Ubuntu)

1. VPN: `sudo ./scripts/install-server.sh out/server/awg0.conf`. Порт **51820/udp** должен быть доступен снаружи.
2. Сайт: `sudo DOMAIN=pm-vpn.3dit.ru EMAIL=<почта> ./scripts/setup-web.sh out/site`. Нужны открытые порты **80 и 443 (TCP)**
   и A-запись домена на сервер. Скрипт ставит nginx, получает сертификат, публикует страницы и скачивает приложения.
3. Проверка: `awg show awg0` (у подключённых клиентов будет свежий `latest handshake`), страница личной ссылки открывается.

Обновить приложения позже: `sudo ./scripts/fetch-apps.sh` (проверяет SHA256, при несовпадении останавливается и оставляет прежнюю версию).
Приложение для iOS с сервера раздать нельзя: на iPhone оно ставится из App Store.

## Выдача сотрудникам

Каждому сотруднику выдаётся его файл `out/qr/clientNNN.png`. По QR открывается личная страница
`https://pm-vpn.3dit.ru/c/<токен>/`: кнопка «Скачать конфиг», ссылка на приложения, инструкция под его систему.
Соответствие «номер → ссылка» лежит в `out/qr-links.csv` (**секретно**: ссылка даёт доступ к приватному ключу).
Раздавайте QR лично или по защищённому каналу; не публикуйте их.

Отозвать доступ одного сотрудника: удалить его блок `[Peer]` из `awg0.conf` на сервере, `systemctl restart awg-quick@awg0`.

Клиентские приложения: на Windows, macOS, Linux и Android Amnezia VPN; на iPhone в российском App Store доступен DefaultVPN
(Amnezia VPN там недоступен). Работу конфига в каждом приложении нужно проверить на реальном устройстве до массовой выдачи.

## Переезд на другой сервер (без перенастройки клиентов)

1. Развернуть новую ВМ (Ubuntu), открыть UDP 51820 и TCP 80/443.
2. Восстановить конфиги (см. выше), выполнить оба шага развёртывания с теми же `awg0.conf` и `out/site`.
3. Переключить A-запись `pm-vpn.3dit.ru` на IP нового сервера. Клиенты подключаются по домену,
   ключи и порт те же, поэтому на устройствах ничего менять не нужно.

Обязательное условие: домен и порт остаются теми, что были при выдаче конфигов.

## Добавление клиентов

Увеличьте `--clients` (например, 170) и запустите `generate.py` и `build_site.py` ещё раз: существующие клиенты
не меняются, добавляются только новые. Обновите `awg0.conf` и сайт на сервере, перезапустите `awg-quick@awg0`,
затем зашифруйте обновлённый `secrets/state.json`:

```bash
tar cz secrets/state.json | age -r <публичный ключ из age-key.txt> -o secrets.tar.age
```

## Изменение списка подсетей

Правка `allowed-ips.txt`, затем `generate.py` и `build_site.py`. Сервер не меняется, но клиентам нужно заново
получить конфиг (через личную страницу) и импортировать его: список подсетей вшит в клиентский файл.
