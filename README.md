# VPN на AmneziaWG (ООО «Тридит»)

Конфигурация VPN-сервера и 150 клиентских подключений. Клиенты направляют через VPN
**только** подсети из `allowed-ips.txt` (заблокированные сервисы), остальной трафик идёт напрямую.

## Что где лежит

| Файл | Назначение |
|---|---|
| `allowed-ips.txt` | Подсети, которые уходят через VPN (попадают в `AllowedIPs` клиентов) |
| `scripts/generate.py` | Генератор ключей, серверного `awg0.conf` и клиентских конфигов |
| `scripts/install-server.sh` | Установка AmneziaWG на Ubuntu и запуск `awg0` |
| `clients.csv` | Список клиентов: имя, IP в туннеле, публичный ключ (секретов нет) |
| `secrets.tar.age` | **Зашифрованные** ключи сервера и клиентов и параметры обфускации |

Репозиторий публичный, поэтому приватные ключи хранятся только в `secrets.tar.age`
(шифрование [age](https://github.com/FiloSottile/age)). Ключ расшифровки `age-key.txt`
в git не попадает: храните его в менеджере паролей. Без него подключения не восстановить.

## Восстановление конфигов из репозитория

```bash
git clone https://github.com/3dit-lab/vpn && cd vpn
age -d -i /путь/к/age-key.txt secrets.tar.age | tar xz      # создаст secrets/state.json
pip install cryptography "qrcode[pil]"
python3 scripts/generate.py --endpoint <ДОМЕН> --port 51820 --clients 150
# результат: out/server/awg0.conf, out/clients/clientNNN.conf
```

Ключи и параметры обфускации берутся из `secrets/state.json` и не меняются, поэтому
клиентские конфиги остаются прежними.

## Переезд на другой сервер (без перенастройки клиентов)

1. Развернуть новую ВМ (Ubuntu), открыть тот же UDP-порт.
2. Восстановить конфиги (см. выше), скопировать `out/server/awg0.conf` на новый сервер и выполнить
   `./scripts/install-server.sh awg0.conf`.
3. Переключить A-запись домена на IP нового сервера. Клиенты подключаются по домену,
   ключи и порт те же, поэтому на устройствах ничего менять не нужно.

Обязательное условие: домен и порт в клиентских конфигах должны совпадать с теми, что были при выдаче.

## Добавление клиентов

Увеличьте `--clients` (например, `--clients 170`) и запустите `generate.py` ещё раз:
существующие клиенты не меняются, добавляются только новые. После этого обновите
`awg0.conf` на сервере и перезапустите `awg-quick@awg0`, затем зашифруйте обновлённый `secrets/state.json`:

```bash
tar cz secrets/state.json | age -r <публичный ключ из age-key.txt> -o secrets.tar.age
```

## Подключение клиентов

Клиентский файл `clientNNN.conf` импортируется в приложение Amnezia VPN («Добавить из файла»)
или в AmneziaWG. Размер конфига около 5,3 КБ из-за длинного списка подсетей, поэтому обычный
QR-код из него построить нельзя (предел QR около 2,9 КБ).

## Проверка

`awg show awg0` на сервере: у каждого подключённого клиента будет свежий `latest handshake`.
